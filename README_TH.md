# Web App Dashboard บุคลากร (ภาษาไทย)

เว็บแอป Dashboard แบบ Responsive สำหรับคอมพิวเตอร์ แท็บเล็ต และมือถือ

## สิ่งที่มีในชุดนี้
- `index.html` — หน้า Dashboard
- `styles.css` — รูปแบบและ Responsive layout
- `app.js` — วาดกราฟและคำนวณค่าบนหน้าเว็บ
- `data.json` — ข้อมูลสรุปรวมเท่านั้น ไม่มีชื่อหรือรหัสพนักงาน

## ข้อควรทราบก่อนเผยแพร่
ชุดข้อมูลปัจจุบันเป็นข้อมูลตัวอย่างจากไฟล์รายชื่อพนักงาน 1,000 คน ไม่ใช่ข้อมูลจริงที่ยืนยันแล้ว
เว็บไซต์สาธารณะนี้ไม่แสดงรายชื่อ รหัสพนักงาน เบอร์โทรศัพท์ หรืออีเมล แต่ตัวเลขสรุปยังสะท้อนชุดข้อมูลต้นทาง
ให้ตรวจสอบว่าได้รับอนุญาตให้เผยแพร่ข้อมูลสรุปดังกล่าว ก่อนนำขึ้นเว็บไซต์สาธารณะ

## ทดลองบนเครื่อง
วิธีแนะนำ (ต้องมี Python ติดตั้ง):
1. แตกไฟล์ ZIP ไปยังโฟลเดอร์หนึ่ง
2. เปิด Terminal/Command Prompt ในโฟลเดอร์นั้น
3. รัน `python -m http.server 8000`
4. เปิด `http://localhost:8000`
5. มือถือที่อยู่ Wi-Fi เดียวกันอาจเปิด `http://IP-ของคอมพิวเตอร์:8000` ได้ หาก firewall อนุญาต

ไม่แนะนำให้ดับเบิลคลิก `index.html` โดยตรง เพราะเบราว์เซอร์บางตัวไม่อนุญาตให้ JavaScript อ่าน `data.json` ผ่าน `file://`

## เผยแพร่ผ่านอินเทอร์เน็ตด้วย GitHub Pages
1. สมัคร/เข้าสู่ระบบ GitHub และสร้าง repository ใหม่
2. อัปโหลดไฟล์ทั้ง 4 ไฟล์นี้ไว้ที่ root ของ repository
3. ไปที่ Settings → Pages
4. ใน Build and deployment เลือก Deploy from a branch
5. เลือก branch `main` และ folder `/ (root)` แล้วกด Save
6. รอให้ GitHub แสดง URL เว็บไซต์ แล้วทดสอบเปิดจากมือถือโดยใช้เครือข่ายมือถือ
7. ทุกครั้งที่แก้ `data.json` หรือไฟล์หน้าเว็บแล้ว commit/push เว็บไซต์จะอัปเดตตาม

## เปลี่ยนข้อมูล
แก้ไข `data.json` ให้เป็นข้อมูลสรุปที่ผ่านการตรวจสอบแล้ว โดยรักษาโครงสร้าง key เดิม เช่น `totalEmployees`, `departmentCount`, `prefix`, `status`, `departments`, `dataQuality`
อย่าใส่ชื่อบุคคล รหัสพนักงาน เบอร์โทรศัพท์ อีเมล หรือข้อมูลส่วนบุคคลลงใน `data.json` เพราะไฟล์นี้จะถูกดาวน์โหลดได้โดยผู้เข้าชมทุกคน

## ความปลอดภัยและการใช้งานในหน่วยงานราชการ
- เว็บนี้เป็น static public dashboard ไม่มีระบบเข้าสู่ระบบ และไม่มีฐานข้อมูลฝั่งเซิร์ฟเวอร์
- ผู้เข้าชมสามารถดูและดาวน์โหลดไฟล์สรุปที่อยู่ในเว็บไซต์ได้ จึงห้ามใส่ข้อมูลส่วนบุคคลหรือข้อมูลภายในที่ไม่อนุญาตให้เปิดเผย
- ใช้ HTTPS ของผู้ให้บริการโฮสต์ และให้ผู้รับผิดชอบหน่วยงานอนุมัติก่อนเผยแพร่
- หากต้องให้เจ้าหน้าที่อัปโหลด Excel จากหน้าเว็บหรือแก้ข้อมูลได้จริง ต้องพัฒนา backend พร้อมยืนยันตัวตน สิทธิ์ผู้ใช้ บันทึกการใช้งาน และสำรองข้อมูลแยกต่างหาก
- ชุดนี้เป็นต้นแบบพร้อมทดสอบ ไม่ได้ถูกเผยแพร่ขึ้นอินเทอร์เน็ตให้อัตโนมัติ การเผยแพร่ต้องทำตามขั้นตอนด้านบน
